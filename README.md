# Forsaken Linux Lite The Isoless Distribution Beyond Time
Forsaken Linux Lite is a lightweight version of the Forsaken Linux distribution designed to run fast on older or lower-specification computers or other architecture that not supported on Regular Forsaken Linux Variant
No ISO Needed!

Supported Architectures

-aarch64

-armv7

-armhf

-loongarch64

-ppc64le

-riscv64

-s390x

-x86_32

-x86_64
